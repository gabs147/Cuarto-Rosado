# Actividad escena cuarto

Se creó una escena de un cuarto con tonos rosados.

## Instrucciones de uso
1. Clona el repositorio: `https://github.com/gabs147/Cuarto-Rosado`
2. Abre el proyecto en tu editor de código.
3. Para ejecutar la pagina abre el archivo `index.html` en tu navegador favorito.

## Tecnologías utilizadas
- HTML
- JS
- CSS
